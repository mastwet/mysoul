# 本体自主日程

模型可以通过 `schedule_wakeup` 决定下一次自主活动的时间。使用现有主体、人格与统一会话，不创建另一个 agent。

```json
{"runtime_call":{"tool":"schedule_wakeup","arguments":{"after_seconds":600,"reason":"休息后继续探索"}},"activity":"rest"}
```

- `after_seconds` 为30到86400秒；`reason` 最多300字符；可选 `goal_id` 绑定已有主人任务。工作工具调用默认绑定当前任务。
- 只有一个下一次安排，新安排替换旧安排。回执给出实际 UTC 时间；心语和聊天状态按本机时间显示。
- 开启自主活动后工具才可用；安排覆盖默认检查间隔。等待时不轮询模型，到点重新决定活动和是否发言。普通聊天和本轮工具操作仍可继续。
- 主人输入优先、主体占用、模式、疲劳、推理预算或上下文不足时，尚未开始的安排保留待处理。普通主人输入不会无故取消它。
- 关联任务取消/放弃、关闭自主活动或会话重置会撤销安排。推理中的关联任务取消会阻止后续工具和发布。
- 重启恢复尚未开始的安排；已开始但中断的轮次标记中断，不自动重放。工具稳定调用 ID 防止检查点重复安排。
- 工具回执只留在当前轮/任务；不写入经历归档、Recap或人格证据。群聊不能安排主人日程；候选测试与正式数据隔离。

在侧栏“心语”查看当前时间和原因；选择“自主日程”筛选查看安排、替换、触发、取消及失败记录。这里只显示模型主动输出的简短说明与实际状态。

这是下一次自主唤醒，不提供固定时刻提醒或多计时器队列。它不启用外部发送，也不绕过既有权限与预算。

## 恢复与检查

运行数据保存在原应用 SQLite 中的 `scheduled_wakeup` / `wakeup_head` 对象；备份时按既有手册完整停止并保存数据目录，包括 SQLite/WAL、检查点、配置及 MemPalace 索引。不要手工重放处于 running、failed、interrupted 的安排。

接口 `GET /api/status` 的 `scheduled_wakeup` 与 `GET /api/inner-voice?category=schedule` 可只读核对。修改默认间隔不会覆盖本体明确安排的时间；关闭再开启自主活动后使用默认间隔。

真实模型工具验证只使用临时数据目录和公开合成文本，不加载正式聊天、Recap或长期记忆。当前网关验证返回 provider_error，不能计作真实模型验收通过。

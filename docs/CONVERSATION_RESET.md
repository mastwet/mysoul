# 会话重置

入口：设置 → 会话 → 重置当前会话 → 归档并重置。点击确认前不会修改数据。

重置会归档当前聊天、清空当前聊天和短期 Recap、停止旧会话待办，并清空当前浏览器的未发送草稿。人格、长期记忆（含 MemPalace 索引与待归档队列）、模型设置、疲劳与累计预算保留。自主功能仍按原来的配置运行，下一次检查从新会话开始。长期细节仍可通过按需回忆工具查阅，因此会话重置不等于遗忘历史。

旧聊天原文和旧摘要版本保留在本机。设置提供“下载上次聊天归档”，导出该次归档的完整分页记录为 JSON，不调用模型。更早的归档也保留，接口 `GET /api/conversation/archives/{revision}?before=...&limit=100` 可分页读取。当前聊天接口只返回本次会话内容。

`POST /api/conversation/reset` 接受 `expected_version`（当前会话版本），复用本机认证、Origin 和 CSRF 校验。重复或过期版本返回 409，避免重试覆盖新聊天。会话边界、空摘要版本、epoch 和任务停止在一个事务中完成；失败整体回滚。旧模型回复、旧任务结果和反馈均不能重新进入当前聊天或短期整理。

浏览器会同步服务端会话版本，清除旧分页缓存并丢弃延迟响应。失败重置保留聊天与草稿；确认成功后，即使状态刷新断线，也会按事务回执清空短期摘要并恢复编辑控件。

开发验收只重置临时数据库。正式运行数据未代用户执行重置。激活前完整备份记录：`.local/conversation-reset-backup.json`。

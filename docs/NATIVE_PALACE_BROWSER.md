# 原生宫殿浏览

在“记忆 → 长期记忆 → 宫殿浏览”查看当前 MemPalace 原生结构。

- 选择 Wing，再选择或筛选 Room；抽屉列表每页显示 20 条逻辑记忆。
- 点击记忆打开完整原文，查看来源、真实 ID、入库时间、分块和本地证据一致性。
- 展开“索引诊断”查看后端、模型、向量停用信息、引擎版本与同步数量。
- “刷新结构”重新读取原生数据。连接失败会保留上次成功的结果并提示重试。

结构计数来自原生 taxonomy，按存储分块统计；列表总数来自原生 list_drawers，按逻辑抽屉统计。已同步来源数来自 mysoul 的本地映射，三者不应混为一个数字。

当前 evidence 房间按来源证据划分，界面不会把它们伪装为主题分类。本功能为只读，不移动、修订或删除已有记忆。管理接口只注册在本机 operator API，未加入模型工具列表。

实现：`src/mysoul/palace.py`、`src/mysoul/web/palace.mjs`，及现有 API、页面和样式中的接入点。

验证：后端/API 21 项通过；含真实隔离 MemPalace 的原生测试模块 4 项通过；前端 39 项通过；Ruff 与 diff whitespace 检查通过。桌面、390px 窄屏、实际原文和诊断均经浏览器检查。未运行无关的全仓库测试。

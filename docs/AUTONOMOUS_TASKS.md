# 自主活动与前后台任务

只有一个主体和一个可见聊天。默认每三分钟进行一次自主检查；检查可以继续工作、发言或保持安静。

- **前台**：当前主人输入及明确启动的有限工作。主人输入提升 epoch，旧检查不能继续发送消息或启动新动作。
- **后台**：一次只推进一个任务；主人明确交代的新任务可持久化排队（最多8项）。每次被选中只推进一个检查点步骤，保留进度、工具结果和固定技能版本；目前仅开放只读记忆与已配置新闻源。后台不会获得文件写入、代码执行或外部发送权限。
- **发布**：后台完成后保留内部结果。后续检查单独决定是否在主聊天分享；记录已分享任务，避免重复报告。后台进度和结果可在任务页查看，不自动变成聊天消息。
- **即时回执**：主动检查读取少量已回应输入和最近实际发言，用于识别旧 Recap 中已经处理的问题。回执来自本地持久化状态，不调用长期记忆搜索，也不作为新的记忆或人格证据反复归档。

日常闲聊或玩笑不会自动被当成持续指令。只有有明确目标、完成条件的后台提案才创建任务；已有任务未结束时不再自主追加新任务。可通过任务页取消，也可在聊天中要求停止。

后台在每步结束后等待下次检查；关闭自主活动会停止后续推进。主人打断、服务重启后仍保留进度；存在不确定动作结果的任务不会自动恢复。旧版本保存的任务默认属于前台，取消后的任务保持终态。

设置中的“自主活动”控制定时检查。三分钟是检查间隔，**不是发言间隔**；安静是正常结果，不向聊天发送“我决定保持安静”之类通知。

设计参考：ALIFE `205aed49434398c0f86f5cbf9cc22535e9e8a2f9` 的系统 Poke、前后台工具执行和统一会话机制。本实现继续采用 mysoul 的 SQLite、LangGraph 检查点和 epoch 权限体系。

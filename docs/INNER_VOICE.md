# 心语：简短决策说明与运行记录

侧边栏“心语”用于观察 mysoul 的选择及排查执行问题，不是原始内部推理展示器。

- 自主检查：显示为什么发言或安静，以及实际发布状态、后台任务状态和检查起止时间。已有记录可以直接查看。
- 对话决策：从上线后的模型返回中保存简短 rationale、所选活动、发言选择、只读记忆工具名及调度轮次。不复制用户输入、回复原文或模型隐藏推理字段。
- 任务进度：显示模型给出的简短进度说明及工具结果状态。工具原文、长期记忆返回片段不复制到日志。
- 记忆整理：展示既有整理阶段、重试及完成状态。

记录按时间倒序，支持类型筛选、实时刷新和加载较早记录；调试详情按需展开。读取失败保留已加载内容；切换页面不会清空聊天草稿。

接口 `GET /api/inner-voice` 复用本机访问保护，默认30项、最多100项；游标绑定稳定时间和记录ID。日志只存在本地应用对象中，不进入归档队列、Recap或人格演化证据。读取页面不会调用模型或搜索长期记忆。

这里只提供简短决策摘要与实际执行信息；模型未给出说明时如实显示缺失，不补写或伪造思考。旧普通聊天和任务不追溯生成新的模型解释。
